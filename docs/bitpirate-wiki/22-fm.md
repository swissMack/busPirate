# FM Mode

The **FM mode** is designed to work with **Si4713 FM transmitter modules**, capable of broadcasting FM signals in the **88–108 MHz band**.  
This mode can be used for RF experimentation, signal analysis, and creating a small local FM broadcast.

## 🧩 Commands
Arguments in `< >` are required, while arguments in `[ ]` are optional.
| Command        | Description |
|----------------|-------------|
| `sweep`        | Scan FM band frequencies and estimate signal activity |
| `trace [freq]` | Observe signal strength at a specific frequency |
| `waterfall`    | Display a waterfall-style visualization of peaks across the FM band |
| `broadcast`    | Enter broadcast FM operations (set freq, power, start stop...) |
| `reset`        | Reset the FM transmitter via the reset pin |
| `config`       | Interactive configuration of the **Si4713 module** |

## ⚠️ Important Warning (Transmission)

- Broadcasting on the FM band may be **regulated or restricted** in many countries.  
- Only transmit on **unused frequencies** and at **very low power** when testing.  
- Avoid interfering with legitimate radio stations.  
- You are responsible for complying with your local regulations.


## 📝 Notes

- The **Si4713** is a digital FM transmitter IC capable of generating FM signals.
- Broadcast the audio input from the 3.5 mm jack as an FM radio signal.
- It supports **RDS (Radio Data System)** metadata such as station name and messages.
- FM signals operate between **88 MHz and 108 MHz**.
- Supports Traffic Announcement (TA) signaling.
- Connect **I2C SDA / SCL** (communication with Si4713) and **RESET pin**

## 📌 Example Usage

```bash
config                 # Configure I2C + reset pin, initialize Si4713
sweep                  # Scan the FM band to detect active stations
trace 101.7            # Monitor signal strength at 101.7 MHz
waterfall              # Display spectrum peaks across the band
broadcast              # Enter broadcast FM operations
```
