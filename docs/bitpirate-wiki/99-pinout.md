# 📌 Pinout Reference

This document summarizes the GPIO pin mappings available for the firmware.


## Cardputer

| Function       | GPIO   | Notes            |
|----------------|--------|------------------|
| Grove Port     | GPIO1 / GPIO2 | General I/O        |
| SD Card        | GPIO40 / GPIO39 / GPIO14 / GPIO12 | SPI interface |
![image](bitpirate-wiki/images/78c68db1ee529460.png)


[M5Stack Cardputer](https://geo-tp.github.io/ESP32-Bit-Pirate/boards/cardputer/)


## Cardputer ADV

| Function       | GPIO   | Notes            |
|----------------|--------|------------------|
| Grove Port     | GPIO1 / GPIO2 | General I/O        |
| Header        | GPIO3 / GPIO4 / GPIO5 / GPI6 / GPIO8 / GPIO9 / GPIO40 / GPI15 / GPI14 / GP13 | SPI/I2C/General |
